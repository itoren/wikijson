**WIKI APP SMALL FLAT FILE**
### **1. Описание скрипта и его функционал**

#### **Что такое WikiAPP?**
WikiAPP — это веб-приложение, которое позволяет пользователям просматривать, искать и переключаться между страницами wiki. Это простое приложение для хранения и отображения информации на основе JSON-файлов.

#### **Как работает приложение?**
Приложение использует две основные технологии:
- **Vue.js**: Для управления интерактивным пользовательским интерфейсом (UI). Vue.js помогает динамически обновлять содержимое страницы без полной перезагрузки.
- **Bootstrap 5**: Для создания красивого и адаптивного дизайна. Bootstrap предоставляет готовые компоненты (например, навигационные меню, кнопки, карточки) и сетку для удобного расположения элементов.

---

### **2. Функциональность**

#### **Список страниц**
- **Где находится список страниц?**
  Список страниц отображается в левой колонке интерфейса. Он загружается из файла `pages-list.json`, который содержит метаданные о всех доступных страницах (название и имя файла).

- **Как работает поиск?**
  В верхней части левой колонки есть поле поиска. Пользователь может ввести текст, и список страниц будет фильтроваться в реальном времени. Например, если пользователь введет "страниц", то будут показаны только те страницы, чьи названия содержат это слово.

---

#### **Просмотр содержимого страниц**
- **Как выбирается страница?**
  Когда пользователь кликает на название страницы в левой колонке, приложение асинхронно загружает содержимое этой страницы из соответствующего `.json` файла в папке `pages`.

- **Откуда берётся контент?**
  Каждая страница имеет свой собственный файл `.json` в папке `pages`. Например, файл `page1.json` может выглядеть так:
  ```json
  {
    "title": "Страница 1",
    "content": "<p>Это содержимое страницы 1.</p>"
  }
  ```
  После загрузки контента он отображается в правой колонке с использованием HTML-тегов (`v-html`), что позволяет форматировать текст.

---

#### **Переключение тем**
- **Какие темы доступны?**
  Приложение поддерживает три режима тем:
  - **Светлая тема** (`light`)
  - **Тёмная тема** (`dark`)
  - **Автоматическая тема** (`auto`), которая определяет предпочтения системы пользователя (если система установлена на тёмную тему, то приложение тоже будет использовать тёмную).

- **Где сохраняется выбранная тема?**
  Выбранная тема сохраняется в `localStorage` браузера. Это означает, что даже если пользователь закроет и снова откроет приложение, тема останется той же самой.

---

#### **Обработка ошибок**
- **Что происходит, если страница не существует?**
  Если пользователь пытается выбрать страницу, которой нет в списке или у которой отсутствует файл `.json`, приложение покажет сообщение об ошибке. Например:
  ```html
  <p class="text-danger">Ошибка: Страница не существует</p>
  ```

### **3. Структура проекта**

#### **index.html**
- Главный файл приложения, содержащий всю разметку и скрипт на Vue.js.
- Здесь подключаются внешние библиотеки (Bootstrap и Vue.js) либо через CDN, либо через локальные файлы.

#### **assets/**
- Директория для хранения статических файлов, таких как CSS и JavaScript библиотек.
- Например, здесь могут быть файлы `bootstrap.css` и `bootstrap.js`. Однако в данном случае они подключены через CDN, поэтому эти файлы фактически не нужны.

#### **pages/**
- Директория с контентом страниц.
- Каждый файл `.json` в этой директории представляет собой отдельную страницу wiki. Например:
  - `page1.json`: Содержит данные для первой страницы.
  - `page2.json`: Содержит данные для второй страницы.
  - `index.json`: Содержит данные для главной страницы.

#### **pages-list.json**
- Этот файл содержит список всех доступных страниц вместе с их метаданными. Пример:
  ```json
  [
    { "filename": "index", "title": "Главная страница" },
    { "filename": "page1", "title": "Страница 1" },
    { "filename": "page2", "title": "Страница 2" }
  ]
  ```
- `filename` — это имя файла `.json` в папке `pages`.
- `title` — это название страницы, которое отображается в левой колонке.
